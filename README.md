# 🛢️ Oil Classification App

Веб-приложение для классификации нефти (light / medium / heavy) на основе физических и химических характеристик с использованием методов машинного обучения.

---

## 🚀 Описание проекта

Данное приложение использует обученную модель машинного обучения для определения типа нефти на основе следующих параметров:

* Плотность (Density)
* Вязкость (Viscosity)
* Температура застывания (Pour Point)
* Температура вспышки (Flash Point)
* Содержание серы (Sulfur)
* Компонентный состав (SARA)

Модель обучена на открытом датасете NOAA Oil Library.

## 📦 Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone <your-repo-url>
cd oil_app
```

---

### 2. Создать виртуальное окружение

```bash
python -m venv .venv
```

---

### 3. Активировать окружение

#### macOS / Linux:

```bash
source .venv/bin/activate
```

#### Windows:

```bash
.venv\Scripts\activate
```

---

### 4. Установить зависимости

```bash
pip install streamlit pandas scikit-learn numpy
```

---

### 5. Запустить приложение

```bash
streamlit run app.py
```

После запуска откроется браузер по адресу:

```
http://localhost:8501
```

---

## 🧪 Использование

1. Введите параметры нефти (можно частично)
2. Нажмите кнопку **Predict**
3. Получите:

   * Предсказанный класс нефти
   * Вероятности по каждому классу
   * Визуализацию результатов

---

## ⚠️ Особенности

* Приложение поддерживает **неполные данные**
* Пропущенные значения автоматически заполняются
* Вероятности отображаются корректно с учетом порядка классов модели

## 📊 Пример работы

Ввод:

```
density = 0.87  
viscosity = 20  
sulfur = 1.5  
```

Результат:

```
MEDIUM
```

Ввод:
```
density = 0.78
viscosity = 3
pour_point = -40
flash_point = 30
sulfur = 0.2
```


Результат:
```

```

Ввод:
```
density = 0.98
viscosity = 200
pour_point = 10
flash_point = 120
sulfur = 4
```


Результат:
```
HEAVY
```
